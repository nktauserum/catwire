# catwire VPN

Кастомная имплементация **виртуальной частной сети** *(VPN)* под Linux. Представляет собой строго учебный проект; не предназначена для обхода блокировок и коммерческого использования. 

Общая идея протокола была вдохновлена Wireguard, но реализована полностью с нуля на Golang. Из сторонних зависимостей помимо стандартной библиотеки только [libsodium](https://github.com/jedisct1/libsodium) для криптографии.

## Принцип работы

Сеть catwire является двуранговой (клиент-сервер). Сервер аутентифицирует входящие соединения и занимается маршрутизацией трафика клиентов во внешний Интернет или между собой. Протокол использует UDP в качестве транспорта для передачи пользовательских пакетов. Контроль за потерями/очерёдностью не осуществляется - это забота более высокоуровневых протоколов.

Первый и главный этап соединения — рукопожатие *(handshake)*. В нём сервер производит аутентификацию клиента по переданному публичному ключу и создаёт новую сессию. На основе своего приватного ключа и полученного публичного другой стороны на клиенте и сервере вычисляется общий секрет с помощью [ECDH](https://en.wikipedia.org/wiki/Elliptic-curve_Diffie%E2%80%93Hellman). В дальнейшем он используется для симметричного шифрования полезной нагрузки пакетов по [AEGIS-256](https://doc.libsodium.org/secret-key_cryptography/aead/aegis-256). Данное семейство криптографических стандартов (AES) имеет высокую производительность благодаря аппаратной поддержке, на процессорах без неё криптография будет работать довольно медленно. Позднее планируется дописать fallback на XChaCha20-Poly1305.

После установки зашифрованного соединения клиент и сервер могут начать общаться друг с другом посредством специальных пакетов. Пакет состоит из 17-байтового заголовка (header) и полезной нагрузки произвольного размера. Последняя может быть зашифрована в зависимости от типа пакета; заголовок же всегда открыт, что, впрочем, не является большой проблемой. Каждый входящий пакет декодируется из байтовых данных, а полезная нагрузка расшифровывается по вычисленному ключу и переданному в header nonce. Исходящие пакеты претерпевают обратную процедуру.

Для маршрутизации всего трафика на системном уровне используются iptables, которые предоставляют NAT для сервера и захват пользовательского сетевого трафика для клиента. Оттого данная реализация пока будет работать только под Linux.

Ввиду своей непопулярности протокол не детектируется системами DPI, и при неправильном выборе локации сервера могут проявиться некоторые побочные явления. Так что ни в коем случае не размещайте свой сервер за рубежом, чтобы случайно не получить доступ к заблокированным ресурсам. Используйте данное ПО лишь в учебных и демонстрационных целях.

## Как запустить у себя?

### Клиент:

Требования: Linux, iptables, Go 1.27.1, libsodium >= 1.0.22

1. Склонируйте проект локально и перейдите в папку catwire/client.
2. Соберите c помощью `go build -o cl client/main.go` 
3. Положите корректный конфигурационный файл для клиента в client/config.ini
4. Запустите скомпилированный бинарник `./cl` с правами root (требуется для TUN-интерфейса и прочей настройки сети)

### Сервер:

Требования: Linux, iptables, Go 1.27.1, libsodium >= 1.0.22

1. Склонируйте проект на свой сервер и перейдите в папку catwire/server.
2. Соберите: `go build -o srv server/main.go`
3. Положите корректный конфигурационный файл для сервера в server/config.ini
4. Запустите скомпилированный бинарник `./srv` с правами root
